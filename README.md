# QR_Code_Generator
Программа на Python, для  создания QR-кода из введённого текста или ссылки с сохранением его в файл формате PNG.
# Генератор QR-кодов с сохранением в файл


## Возможности

- **Интерактивное консольное меню** с пошаговой логикой (state machine) — пользователь не может сгенерировать код, не введя данные
- **Настройка параметров генерации**: размер модуля (`box_size`), уровень коррекции ошибок (L/M/Q/H), цвет кода и фона
- **Умное сохранение файлов**: автоимя с датой и временем (`qr_2026-08-15_14-30-22.png`) или пользовательское имя с проверкой на недопустимые символы
- **Валидация пользовательского ввода**: программа не «падает» при некорректных данных, а вежливо сообщает об ошибке
- **Обработка ошибок файловой системы**: перехват `PermissionError`, `OSError` и других исключений
- **Логирование действий** в файл `qr_generator.log` (INFO / WARNING / ERROR)
- **Предупреждение о совпадении цветов** кода и фона (такой QR может не считаться телефоном)

## Технологический стек

- **Язык**: Python 3.8+
- **Библиотеки**: `qrcode` (генерация QR), `Pillow` (сохранение PNG)
- **Стандартные модули**: `datetime`, `logging`
- **Среда разработки**: Visual Studio Code
- **Система контроля версий**: Git (платформа GitVerse)
- **ИИ-инструмент**: Qwen Chat (использовался для генерации кода валидации и обработки ошибок)
